# lex-ai-bench-es

**Open benchmark for evaluating LLMs on Spanish-language EU regulation (AI Act, GDPR).**

> Work in progress. First stable release expected in late 2026.

## Overview

`lex-ai-bench-es` is an open and reproducible benchmark of 200-500 questions in Spanish
(Iberian Spanish) on European regulation: AI Act (Regulation (EU) 2024/1689) and GDPR
(Regulation (EU) 2016/679). It evaluates 6-8 open-source LLMs in the 7B-9B parameter
range, with LLM-as-judge methodology calibrated against human annotators.

## Why

No existing benchmark simultaneously covers (1) European AI and data protection regulation,
(2) in Spanish, (3) on open-source LLMs, (4) with rigorous human-calibrated LLM-judge
methodology.
